# Validação — Lume 0.4.1

Executada em 10/11/2026, Windows, Python 3.13.9, pypdf 6.19.0 e Node 24.22.1.

30 testes aprovados: 22 Python e 8 JavaScript.

Python: leitura de PDF real, limites de páginas, arquivos vazios/corrompidos/protegidos, extração em diferentes assuntos, preservação de números e negações, seleção de fontes, API HTTP, validação de origem e conteúdo, adaptador de IA com respostas simuladas.

JavaScript: exportação e reabertura, rejeição de fontes adulteradas, escape de HTML, correspondência dos elementos da interface, exemplo, abas, anotações, histórico e destaque de fonte em DOM simulado.

A tentativa de capturar a interface com Edge neste ambiente não produziu imagem. A inspeção visual em navegador real está pendente. Não foi feita inferência com modelo real; o adaptador opcional foi testado por simulação. O iniciador .cmd foi revisado, sem reinstalar dependências neste ambiente.

Este pacote contém somente a leitura geral. O modo especializado pertence ao Edital Claro v0.3. Não inclui integração aplicada ao Licite, OCR ou instalador executável.
