# Interface v0.4.1

Fundo branco e cinza claro, destaque azul, texto em fontes do sistema. Navegação lateral para documentos e histórico. Sem gradientes, sombras decorativas, slogans ou painéis promocionais. A tela de leitura prioriza trechos e fonte; o recurso opcional de IA é secundário.

O CSS inclui adaptação para telas estreitas e redução de movimento. A inspeção visual em navegador está pendente.
